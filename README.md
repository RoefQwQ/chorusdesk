# Chorus

聚合多平台创作者动态的本地浏览器扩展，基于 WXT + Vue 3 + Manifest V3 开发。

[特性介绍](#特性介绍) · [支持平台](#支持平台) · [安装使用](#安装使用) · [文档目录](#文档目录) · [开源协议](#开源协议)

---

平时关注的画师、博主和 UP 主往往分散在 B站、X (Twitter)、YouTube、Pixiv、小红书、微博各个站点。逐个打开网站查看更新不仅繁琐，还容易被平台的推荐算法、广告和乱序时间线干扰。

**Chorus** 是一个纯本地运行的浏览器扩展。它把同一位创作者在不同平台的账号归集在一起，直接在浏览器内拉取并聚合展示他们的最新动态，按发布时间倒序排列，不依赖任何自建后端服务。

## 特性介绍

- **多平台账号归集**：一位现实中的创作者可以绑定多个平台的账号（如同时绑定 B站、推特、Pixiv），动态统一显示在该创作者的名片下。
- **页面一键关注**：浏览创作者主页时，点击扩展图标即可自动识别其平台、UID、昵称与头像，支持新建创作者或归集到已有创作者。
- **无算法纯粹时间线**：采用多列响应式瀑布流展示，支持原图查看与内置媒体灯箱。
- **组合筛选与标签**：
  - 按单个平台快速过滤。
  - 支持仅看原创（过滤转发）、仅看图文多媒体（过滤纯文字）。
  - 支持创作者自定义标签，点击可在 **包含 (+) / 排除 (−) / 全部** 三种状态间循环切换。
  - 右侧栏支持快速临时隐藏某位创作者或其名下的特定平台账号。
- **阅读位置记忆**：支持标记当前阅读位置，无论刷新页面还是在标签页间切换，都可以一键平滑跳回。
- **增量同步与深度回溯**：
  - 常规同步采用增量策略，遇到已缓存动态即停，节省请求开销。
  - 支持针对单个创作者的「深度回溯」，可按数量（如 50/100 条）或时间跨度（如近半年、近一年）拉取历史作品。
  - 支持通过 Chrome Alarms 进行后台定时增量同步并显示未读角标。
- **本地优先与隐私保护**：所有关注数据、抓取的动态、阅读记录和标签全部保存在浏览器本地的 IndexedDB 中，不收集任何用户数据，不设远程服务器。
- **本地图片离线缓存**：支持通过 FileSystem Access API 将动态图片保存到本地硬盘指定文件夹，防止源站删帖或防盗链导致图片失效。
- **导入与导出**：支持将全部数据导出为单个 JSON 文件备份，便于跨设备迁移或重装恢复。

## 支持平台

扩展直接复用你当前浏览器对应平台的登录 Cookie 或公开接口发起请求，不需要在插件里重复输入账号密码：

| 平台 | 域名 | 登录与鉴权方式 | 支持内容 | 历史深度回溯 |
|:---|:---|:---|:---|:---:|
| 哔哩哔哩 | bilibili.com | 复用浏览器 Cookie | 图文动态、视频投稿、转发动态 | 支持 |
| X (Twitter) | x.com | 复用浏览器 Cookie / 页面会话 | 原创推文、转发、图片、视频 | 支持 |
| YouTube | youtube.com | 官方公开 RSS 订阅流（免登录） | 最新视频投稿 | 仅最新 |
| Pixiv | pixiv.net | 复用浏览器 Cookie | 插画、漫画、系列作品（内置防盗链处理） | 支持 |
| Fantia | fantia.jp | 复用浏览器 Cookie | 俱乐部动态、赞助会员专享附件 | 支持 |
| Withny | withny.fun | 复用浏览器 Cookie | 图文动态、赞助更新 | 支持 |
| 小红书 | xiaohongshu.com | 复用浏览器 Cookie | 图文笔记、视频笔记 | 支持 |
| 微博 | weibo.com | 复用浏览器 Cookie | 原创微博、转发、九宫格长图、视频 | 支持 |
| 抖音 | douyin.com | 不读取任何凭据（真实页面采集） | 创作者短视频、图文作品 | 支持（需登录，见下方说明） |
| 通用 RSS / Atom | 任意 XML 源 | 免密公开协议 | 博客、Substack，或搭配 RSSHub 源 | 视源而定 |

> 详细的平台适配说明与网络策略可参考 [平台支持文档](docs/PLATFORMS.md)。

### 外部依赖与固有限制

部分平台的采集方式决定了其可用性**不由本扩展控制**：

- **抖音**：作品列表只能在真实页面中加载（后台请求会被反爬拦截），同步前需在浏览器打开创作者主页并保持标签页开启。深度回溯需在抖音标签页中登录——未登录时平台只放出近期作品，更早内容无法获取。抖音页面改版也可能使采集暂时失效。扩展不读取任何抖音凭据。
- **Twitter / X**：依赖网页客户端的内部接口与会话，平台侧调整（接口变更、风控收紧）会直接导致渠道暂时不可用，常见表现为 429 频率限制；遇到时可稍后重试，或在浏览器打开目标博主主页让扩展复用该会话。
- 两者的**后台自动同步**均受上述约束影响（Twitter 易触发限流、抖音需人工开页），失效时扩展会如实报错说明原因，不会显示虚假的“同步成功 0 条”。

这些是外部平台施加的客观限制，无法通过扩展本地设置消除；详见[用户手册](docs/USER_GUIDE.md) 2.3.1 节。

## 安装使用

### 直接安装（推荐）

1. 在 GitHub [Releases](https://github.com/RoefQwQ/chorusdesk/releases) 下载最新的 `chorus-vX.X.X.zip` 压缩包并解压。
2. 打开 Chromium 核心浏览器（Chrome / Edge / Brave 等），进入扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions/`
   - Edge 地址栏输入 `edge://extensions/`
3. 打开页面右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选中刚才解压出来的文件夹。
5. 将 Chorus 图标固定在浏览器工具栏即可。

### 源码构建

```bash
git clone https://github.com/RoefQwQ/chorusdesk.git
cd chorusdesk

npm install
npm run dev        # 开发热重载模式
npm run typecheck  # TypeScript 类型检查（原生 TS7 编译器）
npm run lint       # ESLint 静态检查
npm test           # Vitest 回归测试
npm run build      # 构建生产包，产物在 .output/chrome-mv3/
```
