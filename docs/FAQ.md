# 常见问题与排错 (FAQ)

本文整理了使用 Chorus 过程中的常见问题与排错方法。

---

### Q1: 推特 (Twitter/X) 同步经常提示 429 或拉不到新推文？
- **原因**：Twitter 官方接口对未授权或频繁请求有限频限制（HTTP 429）。
- **处理建议**：
  1. 确保当前浏览器在 [x.com](https://x.com) 处于已登录状态。
  2. 两次“同步全部”之间适当留出间隔，避免高频连点。
  3. 如果某个博主一直抓不到，可以先在浏览器中新建标签页打开该博主的个人推特主页，之后再点击同步。此时扩展会优先复用当前打开标签页的活跃前端会话来拉取内容。

---

### Q2: 为什么有些图片显示“原图暂无法直接预览”？
- **原因**：
  - 源站博主已删除该动态，或动态被设为仅自己可见。
  - 源站图床 CDN 对访问来源（Referer）有强校验，普通请求被拦截。
  - 动态发布时间较早，源站的历史图片缩略图 CDN 链接已失效。
- **处理建议**：
  - 卡片右下角提供了「原文 ›」链接，点击可在新标签页直接打开源站原帖（**视频类动态**该处显示为「视频动态 ›」，指向同一地址）。
  - 对常看作品，可以在「设置」中开启「本地图片离线归档」，图片拉下来后会自动存到本地硬盘，源站炸图后本地依然能看。
  - **但 RSS 动态不适用这一招**：RSS 的图片托管在发布方主机上，多数拒绝外站引用，扩展取不到也就存不下来；而且源随时可以重新抓取，不需要归档。所以「一键离线」不会为 RSS 动态下载图片——这类卡片请用「原文 ›」直达源站文章查看配图。

---

### Q3: 本地图片离线缓存提示“目录访问权限失效”？
- **原因**：浏览器出于安全策略限制（FileSystem Access API 规范），当浏览器完全退出并重启后，对本地文件夹的读写权限会被操作系统暂时撤销，需要用户手动点击确认一次。
- **处理建议**：
  - 遇到提示时，进入 Chorus 的「设置」→「本地图片缓存」，点击「重新连接本地目录」确认即可恢复。

---

### Q4: 浏览器关闭后后台还会自动同步吗？
- **说明**：
  - 扩展完全运行在本地浏览器的沙箱进程中。当浏览器彻底关闭后，后台 Service Worker 会休眠，不会在后台单独占用系统内存。
  - 浏览器处于运行状态时，定时的 Chrome Alarm 会按设定间隔唤醒 Service Worker 执行增量同步。
  - **已验证（2026-09-11，独立 profile 实测）**：反复打开 Popup 不会重置定时的倒计时——
    连续开 3 次 Popup，前后 4 次读取 `chrome.alarms.getAll()` 的 `scheduledTime` 完全一致。
    这正是它曾经失效的方式（无条件 `create` 会重启倒计时，导致定时器永不触发）。
  - **跨浏览器重启的行为尚不保证**：Chrome 对 alarm 是否随重启保留并无承诺。扩展在
    **每次 Service Worker 启动**时都会检查并补建缺失的 alarm（`setupAutoSync` 中的
    `alarms.get` 守卫），因此只要 Service Worker 被任意事件唤醒就会自我修复；但若重启后
    alarm 已被清除且没有任何事件唤醒 worker，该次同步可能要等到你下次使用扩展才会发生。
    （本机无法实测这一条：调试方式加载的扩展不跨重启留存，重启后重新加载等同全新安装。）
    长期行为仍列在待验证清单（`PROJECT_PROGRESS_2026-09.md` 四.P7）。
  - 需要一直同步，可保持浏览器在后台运行。

### Q5: 换电脑或重装系统后，如何迁移关注列表与动态？
1. **旧电脑导出**：打开 Chorus「设置」→「数据备份与迁移」，点击「导出全量 JSON 数据」，保存备份文件。
2. **新电脑导入**：在新电脑上装好扩展后，在同一设置页点击「选择 JSON 文件导入」，即可恢复所有的关注列表、账号绑定、历史动态、收藏和设置。
   > 备份包含创作者、平台账号、动态（含已读/收藏状态）与设置；**不含回收站内容**（已删除动态的墓碑），也不含开发者日志（会话级诊断数据）。
   > 本地离线归档的图片文件不在备份内，需要在新设备上重新绑定目录并归档。

---

### Q6: 新关注某位作者后，动态列表里只有几条？
- **说明**：
  - 默认的一键同步为了节省流量和避免触发平台风控，每次只抓取最新的一批数据（约 10–20 条）。
- **补全历史动态**：
  - 进入「关注」页，点击该创作者卡片上的「深度回溯」按钮。
  - 选择回溯数量（如 50/100 条）或时间范围（近半年/1 年/全部），扩展会自动逐页向前翻页拉取历史作品。

---

### Q7: 为什么在某些页面点击扩展图标提示无法执行？
- **说明**：
  - 浏览器机制严禁任何扩展在内置页面（例如 `chrome://extensions/`、`edge://settings/`、浏览器空白起始页）中注入脚本。
  - 请在实际的创作者主页（如 `bilibili.com`、`x.com`）中点击扩展图标。
