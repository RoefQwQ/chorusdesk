维护版本。功能与 v1.0.0 相同,修的是发布流程本身,以及一处界面文案。

## 修复

- **发布流程此前会整个失败。** GitHub 的发布接口在 2026-09-13 反复返回 `HTTP 500 / 502`,
  而旧的发布脚本只发一次请求、失败即终止 —— v1.0.0 的四次发布运行全部因此变红。现在改为
  重试并在每次重试后**读取真实状态**判断是否已完成,不再依赖命令的退出码。这条对使用者的影响
  是间接的:它决定后续版本能否正常出现在 Releases 页面。
- **发布说明此前是一行链接。** v1.0.0 的正文只有自动生成的 `Full Changelog` 链接,没有写明
  这个版本是什么、怎么安装、有哪些限制。现在发布说明是仓库里的文件
  (`docs/releases/vX.Y.Z.md`),构建前会被校验,缺失或是空话都会让发布失败。

## 界面

- **浏览器的标签页标题与扩展名不一致。** 标签页此前显示「Chorus - 跨平台创作者动态展台」,
  而扩展在 `chrome://extensions/` 与商店里叫「Chorus - 跨平台创作者聚合展台」。现在两者一致。

## 安装

1. 下载下方的 `chorus-v1.0.1.zip` 并解压
2. 打开 `chrome://extensions/`(Edge 为 `edge://extensions/`),启用右上角**开发者模式**
3. 点**加载已解压的扩展程序**,选择解压出的文件夹

适用于 Chrome / Edge / Brave 等 Chromium 内核浏览器。本版本尚未上架商店,需手动加载。

## 升级

解压新版本**覆盖原目录**,再到 `chrome://extensions/` 点「重新加载」。**本地数据不受影响**
(数据库在 IndexedDB,与扩展目录无关);建议升级前在「设置 → 下载 JSON 备份」留一份备份。
**降级不受支持** —— 数据库迁移是单向的。

## 已知限制

抖音需在浏览器登录后才能回溯更早的作品;X 在请求过密时可能返回 429 限流;两者均不做后台自动
同步。详见[平台支持说明](https://github.com/RoefQwQ/chorusdesk/blob/master/docs/PLATFORMS.md)。

## 反馈

遇到问题欢迎到 [Issues](https://github.com/RoefQwQ/chorusdesk/issues) 反馈;附上「设置 →
开发者日志」里的相关记录会更容易定位。
