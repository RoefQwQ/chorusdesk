**首个公开发布版本。**

Chorus 是一个纯本地运行的浏览器扩展：把同一个创作者在多个平台的账号归到一起，按发布时间倒序聚合展示他们的动态。不需要注册，没有后端服务器。

## 主要能力

- 多平台聚合 —— B站 / X (Twitter) / YouTube / Pixiv / Fantia / 小红书 / 微博 / 抖音 / 通用 RSS
- 同一创作者的多平台账号归集与角色标记（主账号 / 小号 / 里号·差分 / 自定义）
- 无算法时间线：多列瀑布流，七种排序、三种视图、组合筛选与自定义标签
- 页面一键关注、增量同步、后台定时同步与未读角标
- 本地优先：数据存于浏览器 IndexedDB，**无遥测、无远程服务**
- 本地图片离线归档、备份导出 / 导入、开发者日志面板

## 安装

1. 下载下方的 `chorus-v1.0.0.zip` 并解压
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），启用右上角**开发者模式**
3. 点**加载已解压的扩展程序**，选择解压出的文件夹

适用于 Chrome / Edge / Brave 等 Chromium 内核浏览器。本版本尚未上架商店，需手动加载。

## 升级

解压新版本**覆盖原目录**，再到 `chrome://extensions/` 点「重新加载」。**本地数据不受影响**（数据库在 IndexedDB，与扩展目录无关）；建议升级前在「设置 → 下载 JSON 备份」留一份备份。**降级不受支持**——数据库迁移是单向的。

## 已知限制

抖音需在浏览器登录后才能回溯更早的作品；X 在请求过密时可能返回 429 限流；两者均不做后台自动同步。详见[平台支持说明](https://github.com/RoefQwQ/chorusdesk/blob/master/docs/PLATFORMS.md)。

## 反馈

遇到问题欢迎到 [Issues](https://github.com/RoefQwQ/chorusdesk/issues) 反馈；附上「设置 → 开发者日志」里的相关记录会更容易定位。
