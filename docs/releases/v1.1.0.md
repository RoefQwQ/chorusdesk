**小红书历史回溯可用,备份与同步的若干错误修复。**

本次发布的两项功能都来自你的反馈:小红书深挖现在真的能往回取,已绑定本地目录时同步会顺手
把图片存下来。

## 新增

- **小红书历史回溯**。此前回溯只会停在主页那一屏(约 30 条)并报错——更早的笔记需要滚动你的
  已登录页面才能加载,而扩展没有那条路径。现在:
  - 在仪表盘对小红书创作者点「深度回溯」即可往回取更早的笔记。
  - 扩展**不会**导航你已打开的其它小红书标签页;没有可复用的页面时会自行新建后台临时页,
    采集完成后关闭。
  - 采集脚本**只读取页面已渲染的内容**,不读取 Cookie、本地存储、请求头或设备标识,也不调用
    平台的签名接口。
  - **代价由你的账号承担**:连续滚动正是平台风控会留意的行为,所以回溯开始前会先确认;一次
    选中 3 个及以上小红书账号时会额外提醒风控压力叠加、建议分批。若平台弹出验证,请先在对应
    页面完成验证再重试。
  - 常规同步与后台自动同步**不受影响**,仍走原来的轻量路径。
- **同步后自动归档图片**。已绑定本地缓存目录时,同步完成会顺带把这一轮动态的图片与数据存到
  本机——不再需要你先滚动到那条动态才会保存。此前归档只发生在卡片渲染时,于是你没滚到的动态
  等到看见时,签名地址常常已经过期(这正是「原图暂无法直接预览」的成因)。

## 修复

- **小红书笔记链接不再 404**。存储的链接一直没有带上页面为每条笔记提供的 `xsec_token`,
  点击会落到「当前笔记暂时无法浏览」页。同一条笔记在浏览器里能打开、在扩展里打不开,就是这个
  原因。
- **小红书不再谎称「已到底」**。主页只提供一屏时,扩展曾据此判定该账号没有更早的内容并记下
  终点标记,**永久**阻止后续回溯。现在只有确实达到主页标注的数量才记为终点;标注为「1.2万」
  这类缩写则视为未知,永不作为完整性证据。
- **小红书作者名回退路径修复**。两处作者名的兜底写法恒不生效,导致某些页面结构下显示成
  `小红书用户_xxxx` 占位名。
- **Popup 关注时的头像识别修复**。Pixiv 与 Fantia 此前会取网页的分享预览图当头像——Pixiv 取到
  的是一个动态嵌入页(根本不是图片文件),Fantia 取到的是头像背后的横幅。现在两者都改用各自
  的正确来源;没有设置头像的账号则退回首字母头像,而不是一张 1×1 的占位图。

## 安装

1. 下载下方的 `chorus-v1.1.0.zip` 并解压
2. 打开 `chrome://extensions/`(Edge 为 `edge://extensions/`),启用右上角**开发者模式**
3. 点**加载已解压的扩展程序**,选择解压出的文件夹

适用于 Chrome / Edge / Brave 等 Chromium 内核浏览器。本版本尚未上架商店,需手动加载。

## 升级

解压新版本**覆盖原目录**,再到 `chrome://extensions/` 点「重新加载」。**本地数据不受影响**
(数据库在 IndexedDB,与扩展目录无关);建议升级前在「设置 → 下载 JSON 备份」留一份备份。
**降级不受支持** —— 数据库迁移是单向的。

## 已知限制

抖音与小红书需在浏览器登录后才能回溯更早的作品;小红书回溯会滚动你的已登录页面,请自行判断
是否接受该风险。X 在请求过密时可能返回 429 限流。三者均不做后台自动同步,回溯需在仪表盘手动
触发。详见[平台支持说明](https://github.com/RoefQwQ/chorusdesk/blob/master/docs/PLATFORMS.md)。

> 小红书回溯**能否真的加载出第 31 条之后的内容**尚未在真实登录账号上实测过(见
> `docs/XIAOHONGSHU_RESEARCH_2026-09.md` §9)。代码路径、边界校验与失败提示都已就位,但这一步
> 是平台行为,只能实测回答——若你遇到回溯停在第 30 多条不动,那说明还需要换一条路线,欢迎反馈。
