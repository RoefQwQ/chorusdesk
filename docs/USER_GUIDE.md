## 1. 安装插件

### 方式 A：使用 Release 离线包（推荐）
1. 在 GitHub Releases 页面下载 `chorus-vX.X.X.zip` 并解压。
2. 打开 Chromium 核心浏览器（Chrome、Edge 等）：
   - Chrome 地址栏输入：`chrome://extensions/`
   - Edge 地址栏输入：`edge://extensions/`
3. 开启页面右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹（包含 `manifest.json` 的目录）。
5. 点击浏览器工具栏的拼图图标，把 Chorus 固定到工具栏。

### 方式 B：从源码编译
```bash
git clone https://github.com/RoefQwQ/chorusdesk.git
cd chorusdesk
npm install
npm run build
```
构建生成的文件位于 `.output/chrome-mv3/`，在扩展管理页面加载该目录即可。

## 2. 关注创作者与账号绑定

现实中的博主通常在多个平台发布内容。Chorus 支持把同一个人在不同平台的账号合并在同一个创作者卡片下。

### 2.1 在创作者页面一键关注（Popup）
1. 在浏览器中打开支持的博主主页（如 B站 空间、推特主页等）。
2. 点击浏览器右上角的 Chorus 图标。
3. 弹窗会自动提取当前页面的平台、用户 ID、昵称和头像。
4. 确认信息后选择：
   - **新建创作者**：直接建立一个独立的创作者档案。
   - **绑定到已有创作者**：把当前账号归集到列表中已有的某位创作者名下。

### 2.2 在展台手动添加
1. 打开 Chorus 展台，点击右上角「+ 添加创作者」。
2. 输入创作者主页链接（例如 `https://space.bilibili.com/12345` 或 RSS 地址）。
3. 扩展会自动解析平台并抓取信息建档。

### 2.3 抖音创作者的额外步骤

抖音与其他平台不同：它的作品列表只能在真实页面中加载，扩展在后台直接请求主页拿不到任何作品。因此：

1. 添加时请粘贴创作者**主页**链接（`https://www.douyin.com/user/...`）。粘贴单条作品链接无法确定作者身份，扩展会提示你改用主页链接。
2. **同步前请在浏览器打开该创作者主页，并保持标签页开启**。扩展会从这个已打开的页面读取作品列表。
3. 如果没有可用的抖音页面，同步会明确提示需要先打开页面，而不是显示“同步成功 0 条”。
4. 深度历史回溯需要**在抖音标签页中登录**。回溯时扩展会滚动页面加载更早作品；未登录时抖音只放出最新的一部分（例如 29 篇里只给 18 篇）就不再加载，此时会提示「只加载出 X / Y 篇作品，请登录后重试」，登录后可继续回溯剩余作品。
5. 扩展不会读取或保存任何抖音账号凭据（Cookie、Token 等）。登录只发生在你自己的抖音标签页中。

### 2.3.1 抖音与 Twitter 的固有限制（重要）

这两个平台的采集方式依赖真实网页，属于**外部依赖**，其可用性不由 Chorus 控制：

- **抖音**：作品数据来自注入真实页面后的 DOM 读取。抖音页面改版（作品网格结构、滚动容器、封面元素变化）会使采集失效，届时需要等 Chorus 更新适配。未登录时平台只放出近期作品，更早的内容必须登录后才能回溯——这是抖音本身的限制，不是扩展缺陷。
- **Twitter / X**：依赖网页客户端的内部接口（GraphQL operation ID、页面会话）。推特侧调整接口或风控策略会直接导致该渠道暂时不可用，通常表现为同步报错或频率限制提示；遇到时可稍后重试，或在浏览器中打开该博主主页标签页（扩展会优先复用该会话）。
- 两者的**后台自动同步**都受约束：Twitter 频繁请求易触发 429 限流；抖音必须人工打开页面才能采集，自动同步会跳过它并明确提示。
- 这些限制**无法通过本地设置消除**。扩展的原则是：失效时如实报错并说明原因，绝不显示虚假的“同步成功 0 条”。

### 2.4 头像与角色设置
- **更换封面头像**：如果创作者在多个平台使用了不同头像，进入「关注」页面点击其头像，可以在所有关联账号的头像中选择一个作为主头像。
- **标记账号角色**：每个平台账号带有一个角色徽章（**主账号 / 日常小号 / 里号·差分 / 自定义频道**）。在「关注」页面点击该徽章即可循环切换角色；同一创作者下的不同账号可以用角色区分用途。
- **按角色筛选创作者**：「关注」页面的「账号类型」筛选行会列出四种角色及各自的创作者数量，点击只看拥有该类型账号的创作者。

### 2.5 关注列表的排序与整理
「关注」页面右上角的排序下拉菜单提供七种方式：

- **最近活跃**：按最近一次同步或更新时间倒序（默认）。
- **作品数量 / 账号数量**：按已缓存作品数或已绑定账号数排序。
- **字母名称**：按名称排序。
- **标签**：按第一个标签排序。
- **按平台分组**：按创作者首个平台在侧栏中的顺序分组，组内仍按最近活跃排序。
- **手动排序**：开启后可以直接**拖拽**创作者卡片或列表行来调整顺序，调整结果会立即保存。

紧凑列表视图下，**点击表头文字**也能按该列排序（再次点击切换升序／降序）；文字类列默认
A→Z，计数与时间类列默认最新／最大在前。排序下拉与表头共用同一份状态，两者不会互相矛盾。

「关注」页面支持 **网格 / 紧凑列表 / 详细卡片** 三种视图切换，并可用工具栏的「批量操作」
进入多选模式，对选中的创作者执行批量同步或批量删除。

### 2.6 自定义侧栏平台顺序
左侧栏的平台列表可以**拖拽排序**：按住某个平台拖动到目标位置即可，顺序会被记住。未在自定义顺序中的平台（例如新增平台）排在自定义部分之后，按内置注册顺序展示。

## 3. 浏览动态

### 3.1 瀑布流布局与原图查看
- 动态卡片按时间倒序排列，根据图片与内容高度自动排布。
- 点击卡片可标记为已读，点击卡片右下角的「原文 >」可跳转到源站对应帖子。
- 点击图片可打开内置灯箱，支持大图缩放查看和键盘左右键切图。

### 3.2 记录阅读位置
悬浮工具栏只在**「动态」页**出现（这是它唯一的适用场景；「关注」「设置」「收藏」页不显示）。

- **标记位置**：点击定位图标记下当前的滚动位置，底部会提示「已标记当前浏览位置」。
- **返回标记**：滚动离开标记点超过一定距离后，工具栏会多出一个回跳按钮，点击可平滑跳回标记点。
- **回到顶部**：页面下滑超过一定距离时自动出现，位于工具栏最下方。
- 鼠标悬停或键盘聚焦任一按钮时，会在其左侧显示该按钮的名称。

### 3.3 侧栏的两个列表
- **左侧「平台」列表**与**右侧「创作者」列表**都隐藏了系统滚动条，但**仍可正常滚动**
  （滚轮、触控板、方向键均可）。
- **右侧创作者列表会无缝循环**：滚动到底部会继续显示列表开头，可以一直往下翻。
- 该列表的高度可用其**底部的把手拖动**调整（最少 4 行、最多 8 行），设置会被记住；
  把手也支持键盘操作（↑/↓ 调整，Home/End 到两端）。

## 4. 筛选与过滤

展台左右两侧提供了常用的过滤选项：

### 4.1 平台与内容类型过滤
- **平台筛选**：在左侧栏点击对应平台，只看该平台的动态。
- **仅原创 / 含转发**：一键过滤推特 Retweet、微博转发等内容。按钮上的数字是当前转发内容的条数；该状态与设置页的「默认隐藏转发」是同一个开关，两处会同步。
- **仅图文 / 含纯文字**：过滤没有图片或视频的纯文字动态。
- **账号角色筛选**（收藏页）：可按动态来源账号的角色（主账号 / 小号 / 里号 / 自定义）过滤收藏内容。

### 4.2 标签过滤
每个创作者可以打上多个标签（如 `#二次元`、`#摄影`、`#日常`）：
- 点击标签一次为 **正选 (+)**：只看包含该标签的动态。
- 再次点击为 **反选 (−)**：在当前列表中排除该标签的内容。
- 第三次点击恢复为 **中立**。
- 「Detailed」视图中，标签单独占一列并完整展示，点击即可参与上面的三态筛选。
- 收藏页的搜索框也支持 `#标签`：输入 `#摄影` 会连同标签匹配一起过滤。

### 4.3 临时隐藏创作者
- 展台右侧的「创作者」卡片中，点击作者名字右侧的眼睛图标，可以临时隐藏该作者的全部动态。
- 点击卡片可展开其名下的具体平台渠道，支持单独隐藏某个特定账号（例如只看画师的 Pixiv，隐藏推特碎碎念）。

## 5. 动态同步与历史回溯

### 5.1 一键同步全部
- 点击顶栏的「同步全部」，扩展会依次请求所有账号的最新动态。
- 采用增量同步策略，遇到已拉取过的动态或到达同步水位时自动停止。

### 5.2 深度历史回溯 (Deep Sync)
如果新关注了一位作者，想补全其过去发布的内容：
1. 进入「关注」页面，找到目标创作者。
2. 点击创作者卡片上的「深度回溯」按钮。
3. 选择抓取模式：
   - 按数量回溯（如 30 / 50 / 100 条）。
   - 按时间范围回溯（如近 1 个月、近半年、近 1 年或全部）。
4. 过程中可查看抓取进度日志，支持随时暂停。

### 5.3 后台自动同步
- Chorus 支持后台定时自动同步（默认 30 分钟轮询一次）。
- 发现新内容后，浏览器工具栏的图标会显示未读数量角标。

## 6. 收藏与删除管理

### 6.1 收藏动态
- 点击动态卡片上的星标按钮即可加入收藏。
- 被收藏的动态受永久白名单保护，即使后续执行历史数据清理也不会被删除。

### 6.2 删除与回收站
- 点击卡片上的垃圾桶图标可以删除不需要的动态。
- 被删除的动态会自动记入回收站索引（Tombstones）。后续进行「同步全部」时会自动跳过这些条目，不会被重新抓取出来。
- 可以在顶栏同步按钮右侧的下拉菜单中打开回收站，按关键词检索被删记录，支持单条恢复或一键撤回全部删除。

## 7. 本地图片缓存、备份与日志

### 7.1 本地图片离线保存
部分平台的图床有防盗链限制，或者帖文可能被博主自行删除。Chorus 支持把图片直接存到本地磁盘：
1. 进入「设置」→「本地图片缓存与离线归档」。
2. 点击「选择本地存储目录」，选中你电脑上的某个文件夹。
3. 开启后，新抓取的动态图片会在后台自动保存到该文件夹中。
4. 浏览时将优先从本地加载图片，避免图床失效。

归档目录按「创作者 / 平台 / 日期_作品 ID」分层，每个作品的图片以序号命名，可以直接用文件管理器浏览。

### 7.1.1 一键离线当前全部图片（增量）
设置页的「一键离线当前全部图片（增量）」会把已缓存的动态图片批量补存到本地：

- **增量**：先检查每条作品在磁盘上是否**已经完整存在**，已完整缓存的作品直接跳过，不发起任何网络请求。因此重复执行是安全的，第二次几乎不产生流量。
- **并发**：以 3 路并发写盘（瓶颈在网络，该并发度也用于避免触发平台防盗链）。
- **结果**：结束后会报告「新归档 N 张、已缓存跳过 N 条、N 条下载失败」，失败的作品可以先放一放，稍后再次点击即可只重试缺失的部分。

### 7.2 RSS 源需要单独授权
RSS / Atom 源由你自己填写地址，不在扩展内置的平台清单内，因此：

- 首次同步某个 RSS 账号时，浏览器会弹出「允许 Chorus 访问 `<站点域名>`」的授权提示；同意后该源才能被抓取。
- 若拒绝授权，扩展会明确提示并**跳过该 RSS 账号**，其余平台不受影响；再次点击同步可以重新弹出提示。
- 授权按**单个站点**授予，不会一次性放开所有网站。
- 大多数 RSS 源本身允许跨站读取，即使不授权也能抓取；授权只是为那些限制跨站的源提供通道。

### 7.3 JSON 备份与迁移
- **导出**：在设置页点击「导出全量 JSON 数据」，可以把当前的所有关注列表、账号、历史动态、收藏和配置保存为一个文件。
- **导入**：换电脑或重新安装扩展后，在设置页导入该 JSON 文件即可还原所有数据。

### 7.4 开发者日志（问题排查）
设置页的「开发者日志」按钮会打开一个面板，显示扩展在后台做了什么：

- 记录内容：后台消息收发与拒绝、各平台请求的主机与 HTTP 状态、每条账号的同步结果与错误码、自动同步告警触发、RSS 授权结果、离线归档统计。
- 每行标注时间、级别（错误/警告/信息/调试）、模块名，以及是**后台**还是**页面**写入的。
- 支持按级别、模块、关键词过滤，可一键**复制当前筛选结果**用于问题反馈。
- **详细模式**：开启后会额外记录每次请求的明细（主机与结果）。需要排查具体问题时再打开。
- 隐私：日志只存在于**本次浏览器会话**的临时存储中（`chrome.storage.session`），关闭浏览器即清空，**不会**写进数据库，也**不会**被 JSON 备份导出。日志内容只包含主机名、状态码、条数与错误消息，不含 Cookie、Token 或请求头。
