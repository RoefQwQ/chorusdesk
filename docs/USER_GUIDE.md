## 1. 安装插件

### 方式 A：使用 Release 离线包（推荐）
1. 在 GitHub Releases 页面下载 `chorus-vX.X.X.zip` 并解压。
2. 打开 Chromium 核心浏览器（Chrome、Edge 等）：
   - Chrome 地址栏输入：`chrome://extensions/`
   - Edge 地址栏输入：`edge://extensions/`
3. 开启页面右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹（包含 `manifest.json` 的目录）。
5. 点击浏览器工具栏的拼图图标，把 Chorus 固定到工具栏。

### 方式 B：从源码编译
```bash
git clone https://github.com/RoefQwQ/chorusdesk.git
cd chorusdesk
npm install
npm run build
```
构建生成的文件位于 `.output/chrome-mv3/`，在扩展管理页面加载该目录即可。

## 2. 关注创作者与账号绑定

现实中的博主通常在多个平台发布内容。Chorus 支持把同一个人在不同平台的账号合并在同一个创作者卡片下。

### 2.1 在创作者页面一键关注（Popup）
1. 在浏览器中打开支持的博主主页（如 B站 空间、推特主页等）。
2. 点击浏览器右上角的 Chorus 图标。
3. 弹窗会自动提取当前页面的平台、用户 ID、昵称和头像。
4. 确认信息后选择：
   - **新建创作者**：直接建立一个独立的创作者档案。
   - **绑定到已有创作者**：把当前账号归集到列表中已有的某位创作者名下。

### 2.2 在展台手动添加
1. 打开 Chorus 展台，点击右上角「+ 添加创作者」。
2. 输入创作者主页链接（例如 `https://space.bilibili.com/12345` 或 RSS 地址）。
3. 扩展会自动解析平台并抓取信息建档。

### 2.3 抖音创作者的额外步骤

抖音与其他平台不同：它的作品列表只能在真实页面中加载，扩展在后台直接请求主页拿不到任何作品。因此：

1. 添加时请粘贴创作者**主页**链接（`https://www.douyin.com/user/...`）。粘贴单条作品链接无法确定作者身份，扩展会提示你改用主页链接。
2. **同步前请在浏览器打开该创作者主页，并保持标签页开启**。扩展会从这个已打开的页面读取作品列表。
3. 如果没有可用的抖音页面，同步会明确提示需要先打开页面，而不是显示“同步成功 0 条”。
4. 深度历史回溯需要**在抖音标签页中登录**。回溯时扩展会滚动页面加载更早作品；未登录时抖音只放出最新的一部分（例如 29 篇里只给 18 篇）就不再加载，此时会提示「只加载出 X / Y 篇作品，请登录后重试」，登录后可继续回溯剩余作品。
5. 扩展不会读取或保存任何抖音账号凭据（Cookie、Token 等）。登录只发生在你自己的抖音标签页中。

### 2.3.1 抖音与 Twitter 的固有限制（重要）

这两个平台的采集方式依赖真实网页，属于**外部依赖**，其可用性不由 Chorus 控制：

- **抖音**：作品数据来自注入真实页面后的 DOM 读取。抖音页面改版（作品网格结构、滚动容器、封面元素变化）会使采集失效，届时需要等 Chorus 更新适配。未登录时平台只放出近期作品，更早的内容必须登录后才能回溯——这是抖音本身的限制，不是扩展缺陷。
- **Twitter / X**：依赖网页客户端的内部接口（GraphQL operation ID、页面会话）。推特侧调整接口或风控策略会直接导致该渠道暂时不可用，通常表现为同步报错或频率限制提示；遇到时可稍后重试，或在浏览器中打开该博主主页标签页（扩展会优先复用该会话）。
- 两者的**后台自动同步**都受约束：Twitter 频繁请求易触发 429 限流；抖音必须人工打开页面才能采集，自动同步会跳过它并明确提示。
- 这些限制**无法通过本地设置消除**。扩展的原则是：失效时如实报错并说明原因，绝不显示虚假的“同步成功 0 条”。

### 2.4 头像与角色设置
- **更换封面头像**：如果创作者在多个平台使用了不同头像，进入「关注」页面点击其头像，可以在所有关联账号的头像中选择一个作为主头像。
- **标记账号角色**：可以给特定账号打上备注（如“主账号”、“日常小号”），方便在动态中区分来源。

## 3. 浏览动态

### 3.1 瀑布流布局与原图查看
- 动态卡片按时间倒序排列，根据图片与内容高度自动排布。
- 点击卡片可标记为已读，点击卡片右下角的「原文 >」可跳转到源站对应帖子。
- 点击图片可打开内置灯箱，支持大图缩放查看和键盘左右键切图。

### 3.2 记录阅读位置
- **标记位置**：在展台右下角的悬浮工具栏中，点击定位图标可以记下当前的滚动位置。
- **返回标记**：当滚动离开标记位置超过一定距离后，悬浮栏会显示回跳按钮，点击可平滑跳回标记点。
- **回到顶部**：页面下滑超过一定距离时，自动显示回到顶部按钮。

## 4. 筛选与过滤

展台左右两侧提供了常用的过滤选项：

### 4.1 平台与内容类型过滤
- **平台筛选**：在左侧栏点击对应平台，只看该平台的动态。
- **仅原创 / 含转发**：一键过滤推特 Retweet、微博转发等内容。
- **仅图文 / 含纯文字**：过滤没有图片或视频的纯文字动态。

### 4.2 标签过滤
每个创作者可以打上多个标签（如 `#二次元`、`#摄影`、`#日常`）：
- 点击标签一次为 **正选 (+)**：只看包含该标签的动态。
- 再次点击为 **反选 (−)**：在当前列表中排除该标签的内容。
- 第三次点击恢复为 **中立**。

### 4.3 临时隐藏创作者
- 展台右侧的「创作者」卡片中，点击作者名字右侧的眼睛图标，可以临时隐藏该作者的全部动态。
- 点击卡片可展开其名下的具体平台渠道，支持单独隐藏某个特定账号（例如只看画师的 Pixiv，隐藏推特碎碎念）。

## 5. 动态同步与历史回溯

### 5.1 一键同步全部
- 点击顶栏的「同步全部」，扩展会依次请求所有账号的最新动态。
- 采用增量同步策略，遇到已拉取过的动态或到达同步水位时自动停止。

### 5.2 深度历史回溯 (Deep Sync)
如果新关注了一位作者，想补全其过去发布的内容：
1. 进入「关注」页面，找到目标创作者。
2. 点击创作者卡片上的「深度回溯」按钮。
3. 选择抓取模式：
   - 按数量回溯（如 30 / 50 / 100 条）。
   - 按时间范围回溯（如近 1 个月、近半年、近 1 年或全部）。
4. 过程中可查看抓取进度日志，支持随时暂停。

### 5.3 后台自动同步
- Chorus 支持后台定时自动同步（默认 30 分钟轮询一次）。
- 发现新内容后，浏览器工具栏的图标会显示未读数量角标。

## 6. 收藏与删除管理

### 6.1 收藏动态
- 点击动态卡片上的星标按钮即可加入收藏。
- 被收藏的动态受永久白名单保护，即使后续执行历史数据清理也不会被删除。

### 6.2 删除与回收站
- 点击卡片上的垃圾桶图标可以删除不需要的动态。
- 被删除的动态会自动记入回收站索引（Tombstones）。后续进行「同步全部」时会自动跳过这些条目，不会被重新抓取出来。
- 可以在顶栏同步按钮右侧的下拉菜单中打开回收站，按关键词检索被删记录，支持单条恢复或一键撤回全部删除。

## 7. 本地图片缓存与数据备份

### 7.1 本地图片离线保存
部分平台的图床有防盗链限制，或者帖文可能被博主自行删除。Chorus 支持把图片直接存到本地磁盘：
1. 进入「设置」→「本地图片缓存与离线归档」。
2. 点击「选择本地存储目录」，选中你电脑上的某个文件夹。
3. 开启后，新抓取的动态图片会在后台自动保存到该文件夹中。
4. 浏览时将优先从本地加载图片，避免图床失效。

### 7.2 JSON 备份与迁移
- **导出**：在设置页点击「导出全量 JSON 数据」，可以把当前的所有关注列表、账号、历史动态、收藏和配置保存为一个文件。
- **导入**：换电脑或重新安装扩展后，在设置页导入该 JSON 文件即可还原所有数据。
